## Reproduction

Use Python 3.13 with the checked-in dependency lock and `node --test tests/*.mjs`. The scripts `verify-native-packets.py`, `verify-native-viewer.mjs`, `benchmark-native.py`, and `benchmark-viewer.mjs` create or use isolated temporary proof projects. Browser scripts accept `STUD_PYTHON`, `STUD_PLAYWRIGHT_MODULE`, and `STUD_CHROME`; viewer timing uses SwiftShader by default and the real hardware backend when `STUD_RENDERER=default`.

The acceptance record includes executed commands, native runtime observations, rendered artifacts and the owner's reader result. Local tests, native installations, production signed updates and reader usability are recorded separately.
