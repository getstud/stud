# Realistic visualization

1. Read the displayed design and active editing target through the viewer tools. A request such as “Show me how this would look with cedar siding” asks for both a design change and a generated image. Make the material change through the normal project request workflow, including its material specifications and finish choices. Capture the edited source, explicitly evaluate it, wait and inspect the result, then finish that request. If `finish` returns `evaluation_required`, evaluate the current source before retrying. If the displayed saved option differs from the editing target, resolve the intended edit target first. A request only for lighting, a viewpoint or a realistic rendering leaves source unchanged.
2. Match the viewer to the resulting complete build. Use `show` or camera tools when a particular viewpoint is requested; otherwise keep the existing camera. Capture with `capture_render_reference`, supplying the displayed `expected_revision` and relevant `finishes`/`lighting`. Resolve incomplete/stale build errors before continuing. The tool returns a geometry PNG and brief with the displayed source/build/checkpoint, camera and materials.
3. Inspect `reference_path` and use the available image-generation skill/tool with that PNG as the authoritative geometry/camera reference and the returned `brief.prompt`. Supplement the prompt only with known material/finish details and the user's requested lighting. Require preservation of silhouette, proportions, openings, joints, part layout and viewpoint. Capturing the reference is preparation; complete the request by generating the image. If generation is unavailable or fails, report it explicitly.
4. Present the generated image directly in chat. Compare it to the reference for geometry, proportions, viewpoint and material assignment; disclose specific visible drift and iterate when needed. Save project-bound generated outputs in the design project with the reference/brief and retain earlier versions. Keep the interactive viewer open for inspection. Another viewpoint requires a new reference capture.

The rendered image is an appearance study. Dimensional checks belong to the 3D design. Preserve its modeled materials separately from image-generation finish/lighting text. Surroundings-photo placement is outside this feature.
